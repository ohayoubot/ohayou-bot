    Joining in

    The chatroom is on IRC, in the channel. IRC is a chat network that has been running since 1988; you talk to it with a program called a client, and there is nothing to sign up for.

    The quickest way in is a client that runs right here. Nothing is loaded from the chat network until you ask for it.
