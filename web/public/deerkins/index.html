    Lowercase letters, numbers, spaces, - and _. Taken names get a random suffix.

    About

    A drawing grid that uses the 16 mIRC colours. When you save, you get two text forms of the drawing: kinskode, the one-character-per-cell format this site stores, and IRC codes, which you paste into a channel.

    Saved art is public domain. It can be removed at any time.

    deerkins and deeritor were written by pihl. cvaj forked them as doodlebutt, which was forked again as artbutt. This fork is by ohayoubot; the source is at github.com/ohayoubot/deerkins.
