    About

    A drawing grid with the 16 mIRC colours in it. Saving gives you two text forms of the picture: kinskode, one character per cell, which is what this site keeps, and IRC codes, which you paste into a channel.

    Saved art is public domain, and can be taken down at any time.

    deerkins and deeritor were written by pihl. cvaj forked them as doodlebutt, which was forked again as artbutt. This fork is by ohayoubot; the source is at github.com/ohayoubot/deerkins.
